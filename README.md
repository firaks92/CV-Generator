# Конструктор резюме с ИИ (CV Generator)

Современный веб-сервис для создания персонализированных профессиональных резюме, сопроводительных и рекомендательных писем с помощью искусственного интеллекта.

Разработан в строгом соответствии с **PRD**, **SPEC** и **DESIGN**. Никакого нейрослопа — только продуманный UX, высокая типографика, адаптивность и реальная ценность для соискателя.

---

## ✨ Ключевые возможности

1. **Интеллектуальная форма ввода (5 шагов wizard):**
   - 📸 **Фотография** с моментальным предпросмотром, обрезкой и валидацией до 5 МБ.
   - 👤 **Личные данные:** Ф.И.О., желаемая должность, год рождения, город проживания, контакты (телефон, email).
   - 💼 **Опыт работы:** Общее текстовое описание для синтеза Summary и динамический список прошлых мест работы с оцифрованными достижениями (KPI).
   - 🛠 **Навыки и стек:** Теги с автодополнением, категоризацией (Hard/Soft/Tool/Language) и шкалой владения (1-5).
   - 🎓 **Образование:** ВУЗы, специальности, ученые степени и годы обучения.

2. **ИИ-ассистент (Google Gemini + умный эвристический fallback):**
   - 🤖 **Professional Summary:** Автоматическая формулировка лаконичного описания кандидата в 3-5 предложениях от третьего лица.
   - ✅ **Сильные стороны:** Выделение ключевых преимуществ профиля, которые подсвечиваются прямо в шаблоне резюме.
   - 📈 **Зоны роста:** Конструктивный разбор потенциальных пробелов и действенные советы (отображаются только пользователю и **не попадают в финальный PDF**).
   - ✉️ **Мотивационное письмо (Cover Letter):** Генерация убедительного сопроводительного письма под конкретную компанию и должность на основе опыта соискателя.
   - 📝 **Рекомендательное письмо:** Составление официальной рекомендации от лица руководителя или коллеги.

3. **5 авторских дизайн-шаблонов:**
   - 🏛 **Classic** — строгий корпоративный двухколоночный макет (sidebar 32% / main 68%).
   - 🌿 **Modern** — чистый одноколоночный минимализм с центрированной шапкой и аккуратными чипами навыков.
   - 🎨 **Creative** — выразительный дизайн с акцентной шапкой, круглым аватаром, прогресс-барами навыков и звездами достижений.
   - 📊 **Compact** — максимальная плотность информации (9-10pt), строго рассчитанная на 1 страницу для технических специалистов.
   - 👔 **Executive** — премиум-типографика Playfair Display с двойными линиями и акцентом на лидерские достижения для C-level и ведущих экспертов.

4. **7 цветовых палитр:**
   - 🔵 Ocean Blue (`#1E3A5F` / `#4A90D9`)
   - 🟢 Forest Green (`#2D6A4F` / `#40916C`)
   - 🔴 Ruby Red (`#991B1B` / `#DC2626`)
   - 🟣 Royal Purple (`#581C87` / `#7E22CE`)
   - ⚫ Monochrome (`#1F2937` / `#4B5563`)
   - 🟠 Sunset Orange (`#C2410C` / `#EA580C`)
   - 🎨 **Custom** — интерактивный колор-пикер для настройки Primary, Accent, Background и Text цветов в реальном времени.

5. **Экспорт в PDF:**
   - 🖥 **ПК-версия (A4):** Векторная отрисовка в стандартном формате 210 × 297 мм для печати и отправки работодателю.
   - 📱 **Мобильная версия:** Вертикально ориентированный компактный PDF для мгновенного просмотра на смартфонах и в мессенджерах.
   - 📄 Экспорт мотивационного и рекомендательного писем в отдельные PDF-документы.

6. **Премиальный интерфейс и UX:**
   - Тёмная тема оформления по умолчанию (Corporate Dark) + переключатель на светлую тему.
   - Split-view 50/50 на десктопе: форма слева, живое интерактивное превью справа.
   - Мобильный адаптив с удобной нижней панелью переключения («Форма» / «Превью»).
   - Кнопка «Пример резюме» для мгновенной загрузки реалистичных данных.

## 🚀 Запуск проекта

### 1. Установка зависимостей (уже установлены)
```bash
npm.cmd install
```

### 2. Запуск локального сервера разработки
```bash
npm.cmd run dev
```
Приложение откроется по адресу: [http://localhost:3000](http://localhost:3000)

### 3. Сборка для продакшена
```bash
npm.cmd run build
npm.cmd start
```

### 4. Настройка API-ключа Gemini (опционально)
В файле `.env.local` укажите:
```env
GEMINI_API_KEY=ваш_ключ_gemini
```
*Если ключ не указан, приложение автоматически задействует встроенный отказоустойчивый эвристический ИИ-движок, гарантируя 100% работоспособность офлайн или без внешних подписок.*

## 🛠 Технологический стек

- **Фреймворк:** Next.js 14 (App Router, TypeScript)
- **Стилизация:** Tailwind CSS, CSS Custom Properties
- **Шрифты:** Playfair Display, Lora, JetBrains Mono
- **Стейт-менеджмент:** Zustand
- **ИИ:** Google Generative AI (`gemini-1.5-flash`)
- **PDF-генерация:** jsPDF + html2canvas
- **Иконки:** Lucide React
